Design a modern, premium, and user-friendly website for **Morent**, a car rental platform.

You have complete creative freedom over the **color palette, typography, visual style, imagery, layout, branding, and overall art direction**.

The goal is to create a polished, realistic, production-quality **UI/UX design** for a modern car rental platform.

Focus entirely on the **visual design and user experience**. Do not focus on implementation details, code, frameworks, component architecture, or technical functionality.

You are also free to introduce **additional sections, content blocks, UI elements, or supporting information** on the specified pages whenever they improve the overall experience. However, keep the main user flows and required sections described below.

---

# 1. Homepage

Create a visually impressive homepage that introduces Morent and helps users discover rental vehicles.

Include a strong **hero section** with:

- A compelling headline related to car rental
- Supporting text
- A clear primary CTA
- An attractive automotive visual

Include a **Popular Vehicles** section displaying several popular rental cars.

Each vehicle card should visually communicate:

- Vehicle image
- Brand
- Model
- Vehicle type
- Key specifications
- Daily rental price
- A clear action such as "View Details"

Clicking a vehicle should lead to its **Vehicle Detail Page**.

Include a prominent **"View All Vehicles"** CTA that leads to the **Vehicles Page**.

You are free to add other homepage sections that make sense for a professional car rental platform, such as promotional areas, benefits, how-it-works sections, customer reviews, featured categories, statistics, or other relevant content.

---

# 2. Vehicles Page

Create a dedicated page where users can browse the complete collection of rental vehicles.

The page should include a clear vehicle discovery experience with:

### Search

A prominent search field for searching vehicles by:

- Brand
- Model
- Vehicle name

### Filters

Include relevant vehicle filters such as:

- Vehicle type
- Brand
- Price range
- Transmission
- Fuel type
- Number of seats
- Other useful vehicle attributes

### Sorting

Allow users to visually sort vehicles by options such as:

- Price: Low to High
- Price: High to Low
- Popularity
- Newest

### Vehicle Listing

Display vehicles in a visually appealing responsive grid.

Each vehicle card should include:

- High-quality vehicle image
- Brand and model
- Key specifications
- Daily rental price
- Clear CTA

Clicking a vehicle should lead to its **Vehicle Detail Page**.

### Pagination

Include a clear pagination system for browsing large numbers of vehicles.

The design should communicate how search, filters, sorting, and pagination work together.

You are free to add additional sections or useful UI elements to this page if they improve the browsing experience.

---

# 3. Vehicle Detail Page

Create a premium vehicle detail page where users can fully explore a selected vehicle and start the rental process.

### Image Gallery

Create a prominent image gallery containing multiple photos of the vehicle from different angles.

Include:

- Large primary image
- Thumbnail images
- Image navigation
- Elegant gallery interactions

The vehicle photography should be one of the strongest visual elements of the page.

### Vehicle Information

Clearly present important vehicle information such as:

- Brand
- Model
- Vehicle type
- Daily rental price
- Transmission
- Fuel type
- Number of seats
- Luggage capacity
- Other relevant specifications

### Vehicle Description

Include a well-designed area describing the vehicle and its main characteristics.

### Reservation Form

Create a prominent reservation area where the user can select when they want to rent the vehicle.

The reservation form should contain:

**Rental Start**

- Date
- Time

**Rental End**

- Date
- Time

**Additional Notes**

- Textarea for additional requests or information

Include a clear **"Reserve Now"** button.

### Reservation Summary

Visually display:

- Selected vehicle
- Rental start date and time
- Rental end date and time
- Total rental duration
- Daily rental price
- Estimated total price

The reservation area should feel trustworthy, clear, and easy to use.

You are free to add additional sections to the detail page where appropriate, such as vehicle features, rental conditions, included services, similar vehicles, customer reviews, location information, or other useful content.

---

# Main User Flows

The primary experience should support these flows:

**Homepage → Popular Vehicles → Vehicle Detail → Reservation**

and

**Homepage → View All Vehicles → Search / Filter / Sort → Vehicle Detail → Reservation**

Keep these flows clear and intuitive while using your own design judgment to enhance the overall experience.

---

# Overall Design Direction

Make **Morent** feel like a modern, premium, trustworthy, and established car rental brand.

You have complete freedom to determine:

- Color palette
- Typography
- Visual identity
- Layout style
- Photography direction
- Cards
- Buttons
- Spacing
- Borders
- Shadows
- Gradients
- Icons
- Decorative elements
- Overall visual language

Do not constrain the design to a predefined color scheme.

Prioritize **strong visual hierarchy, premium automotive imagery, intuitive UX, whitespace, consistency, and a high-end professional aesthetic**.

The final design should feel like a **real-world production-ready car rental platform**, not a generic template.
